# Bun Afaka

Шрифт для **Афаки** — слоговой письменности языка ндюка (Суринам), которую придумал Афака
Атумиси в 1908–1910. Набираешь ндюка латиницей — получаешь Афаку.

```
source/*.svg → ./scripts/build.sh → dist/{otf,ttf,woff2}/BunAfaka-Regular.*
```

Первый запуск создаёт `.venv`. Конвейер сборки — `scripts/svgfont/`, копия из скилла
`svg-font-builder`, чтобы репозиторий собирался сам по себе. FontForge не нужен: `source/_old/bunafaka.sfd` — версия 1
(март 2026), оставлена как есть.

## Как читаются имена файлов

- `ka.svg` — слог *ka*. Несколько слогов на одном знаке пишутся через дефис: `bo-bu.svg`.
- `b.svg`, `n.svg`, … — рукописная латинская буква. В Афаке знаков для отдельных согласных нет,
  поэтому эта буква показывается, когда набранная согласная не образует слог. Так задумано:
  пока слог набран наполовину, что-то уже видно, но буква достаточно другая, чтобы её не приняли
  за знак Афаки.

## Что делает набор (всё в `scripts/model.py`)

| Правило Афаки | Набор |
|---|---|
| o/u не различаются | `gu` → GO, `du` → DO, `mu` → MO, `nu` → NO |
| e/i сливаются после l, m, s, w | `li` → LE, `mi` → ME (`se` и `si` нарисованы отдельно — остаются разными) |
| BA — это и *ba*, и *pa*; U — это и *u*, и *ku* | по именам файлов `ba-pa`, `u-ku` |
| конечные n, m не пишутся | `kon`, `kom` → KO; но `kona` → KO NA |
| преназализованные = простые | `mba` → BA, `nda` → DA, `anga` → A GA |
| долгие гласные повторяются | `koo` → KO O |
| глайд пишут и *y*, и *j* (старая голландская орфография) | `ja` → YA, `tja` → TYA, `djo` → DYO, `nja` → NYA |

Регистр не важен. Проверки — `scripts/check_shaping.py`.

## Чего нет

Сборка печатает этот список каждый раз. На 1 нояб. 2026 нарисованы все 57 букв и точка
(длинная вертикальная черта, набирается `.`). Не хватает двух знаков: восклицания (столбик
колечек) и кометы Галлея. Знаки препинания лежат под словами (`period.svg`), а не под символом:
файл `.svg` был бы скрытым. Новый знак — строка в `PUNCTUATION` в `scripts/model.py`.

Источник: M. Everson, *Proposal for encoding the Afáka script in the SMP of the UCS*,
WG2 N4132R (2011).
